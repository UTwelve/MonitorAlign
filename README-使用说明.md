# MonitorAlign 显示器对齐工具 · v2.0.2

本版修复卸载清理范围、显示排列失败回滚、泛光钩子生命周期、托盘页面门控、主题解析与颜色编辑状态；保留 v2.0.1 的 WinUI 原生布局改进。
测量标尺的交互问题本版暂不处理，仍保留为待验证功能。

帮助把多块显示器**在视觉上真正对齐**：读取系统显示排列、自动分析拼接方式，在接缝两侧生成**对齐标尺**，
拖动副屏标尺对齐后自动换算成精确的显示排列偏移并写入系统。

绿色目录，**双击 `MonitorAlign.exe` 即用**：不需要安装、不需要装 .NET 运行时、不需要 Windows App SDK 运行时
（已自包含）。想装到「应用列表」里、要开始菜单与卸载入口，就用安装包 `MonitorAlign-Setup-2.0.2.exe`。
唯一的存档是 exe 同目录的 `MonitorAlign.settings.json`（记录标尺位置与泛光设置，详见文末「关于设置存档」）。

**v2.0.0 是一次界面重构：从 WPF 换成 WinUI 3（Windows App SDK）原生实现。**
功能与 v1.6.0 一一对应，观感换成系统原生的一套 —— `NavigationView` 导航栏、Mica 材质、
原生标题栏与滚动条、Segoe Fluent 图标、`ToggleSwitch` / `NumberBox` / `Slider` / `ComboBox` / `ListView`
全部是 WinUI 原生控件，不再手搓样式，和系统「设置」页是同一套设计语言与同一套控件。

界面语言**跟随系统**：中文系统显示中文，其它语言一律显示英文。
想手动指定时用 `--lang zh` 或 `--lang en`。

## 怎么用

打开程序，**对齐标尺立刻出现**在接缝两侧，没有需要点的按钮。

> 左侧有一条**导航栏**：①「显示器对齐」（主业）②「边缘泛光」③「扩展功能」（双标尺测量目标分辨率），
> 底部固定一枚**设置**（齿轮）。**只有停在「显示器对齐」页时标尺才会显示**，
> 切到其它页标尺会自动隐藏，切回来恢复。

1. **拖动**副屏上的对齐标尺，直到**两侧线段在接缝处连成一条笔直的长线**；
2. **松手**即自动计算并写入系统（屏幕会闪一下，属正常）；
3. 需要精修时用标尺按钮条上的 `▲▼` / `◀▶` 键，或方向键，每次 ±1px（按住 Shift 为 ±10px）；
4. 满意就直接关闭程序——改动已经写进系统，会一直保留。

后悔了？点 **「撤销修改」**（或按 Esc）即可回到本次启动前的排列。

多屏时缩略图上每条接缝的中点有一枚**接缝点**：**实心蓝点 = 正在对齐的接缝**，空心点表示其余接缝，鼠标悬停可看接缝信息，点击即切换并把标尺挪过去。

### 标尺上的按钮条

两侧标尺各带一段圆角**按钮条**，组合成一个整体（不再是散落的几枚按钮）：

| 侧 | 按钮条 | 说明 |
| -- | ------ | ---- |
| 基准侧 | **[≡ 拖动][↺ 重置]** | 沿线并排，**拖动键永远靠接缝一侧**（四方位自动镜像）；↺ 一键回到接缝居中 |
| 副屏侧 | **[▲][≡][▼]**（或 [◀][≡][▶]） | 沿移动方向三键成串：上下（左右）是 ±1px 微调，**中间的 ≡ 是拖动键**，条上任何空白处也能按住拖动 |

基准侧的「对齐标尺 · 基准」标签与副屏侧的读数浮标都排在按钮条外侧，不再与按钮或标尺线互相遮挡。

## 边缘泛光（导航第二项）

开启后，**鼠标靠近两块屏幕的交界处时，交界处会泛起一层辉光**——
把它想成一根**贴着接缝的矩形光源**：贴近接缝处是一条发白的高亮灯芯（真实光源的亮度感），
光晕向两侧屏幕按指数衰减地「照射」出去。辉光范围正好是两块屏幕实际相接的那一段，
不用打开设置，凭余光就能感知每块屏幕的边界在哪。

光标越贴近接缝辉光越亮（快进慢出），离开即柔灭；最高亮度刻意压得很低，只是氛围提示。
对所有相邻屏幕的接缝生效；孤立屏幕没有交界处，不参与。
泛光窗口置顶但**完全不遮挡点击**（空白处点击穿透到桌面）。

### 效果设置

泛光页可全局调节，改动即时生效并记入存档：

| 设置 | 说明 |
| ---- | ---- |
| 启用边缘泛光 | 总开关 |
| 接近灵敏度 | 倍数：光标多近开始起辉（起辉距离 = 120px ÷ 倍数），0.25×–8× |
| 发光亮度 | 辉光整体亮度（滑条，5%–100%） |
| 光晕距离 | 可手填 8–20000 px，已放开原来的 320 px 限制 | 
| 加性强度 | 提高外圈白度以减轻亮背景压暗，是 ADD 的视觉近似，不是真正加法混合 |

### 接缝自定义颜色

缺省每条接缝用**主题强调色**发光。在「接缝颜色」卡片的下拉框里选一条接缝、点 **+**，
点击色块按钮打开 WinUI 原生取色弹窗，可拖动色盘或输入十六进制（如 `#4CC2FF`）。
「完成」保留颜色；「取消」或 Esc 恢复打开前的颜色及主题跟随状态。「主题色」可一键还原。

### 扩展功能：计算目标分辨率（导航第三项）

选取接缝并点「放置标尺」，两端各出现一对标尺。基准侧固定，拖动副屏两枚标尺，
直到每对在物理上连成直线；页面计算像素尺度比与保持宽高比的目标分辨率，支持复制。
可归零或移除标尺；离开页面会收起标尺。

**本功能只做计算，不修改系统显示设置。** 结果假设画面均匀缩放并铺满面板，
是参考目标，不能保证显示器或驱动支持该自定义分辨率；EDID 尺寸仅用于交叉参考。
列表外的接缝一律跟随主题色，换主题时自动跟着变。

### 后台常驻与开机自启

泛光开着时**关闭主窗口不会退出程序**——它会缩到系统托盘（右下角）继续提供泛光；
右键托盘图标可「打开」窗口或真正「退出」。再启动 exe 时也会把托盘里的窗口唤出来（单实例）。

设置页（导航底部齿轮）里有**开机自动启动**开关：勾选后随 Windows 静默启动到托盘，
泛光直接按上次的设置恢复生效。

## 名词说明

程序里只有两个可动的东西，都叫**对齐标尺**，区别在职责：

| 位置 | 名称 | 说明 |
| ---- | ---- | ---- |
| 主屏侧 | **对齐标尺 · 基准** | 对齐时的参照。也可以**拖动**——拖它会把两侧的标尺一起沿接缝挪动（只移动标尺，不改屏幕），方便你不在接缝正中、而是靠边等位置对齐；点按钮条上的 **↺** 一键回到接缝居中 |
| 副屏侧 | **对齐标尺 · 可拖动** | 拖它改变的是**对齐量**：拖到与基准线连成一条直线，松手即写入系统 |

两侧的标尺各自带一个指向接缝的**三角箭头**：箭头尖对准接缝，两条线在接缝处是否连成直线，就是判断依据。

## 界面说明

| 区域 | 含义 |
| ---- | ---- |
| 显示器排列 | 缩略图：**蓝=主屏（基准）**，灰=其余屏幕，深浅表示离主屏的链深；接缝中点的圆点用来切换要对齐的接缝；当前接缝上的**两条短线**实时显示两侧标尺的位置 |
| mm/px | 该屏上 1 逻辑像素对应的物理宽度，用来判断误差是否肉眼可见（如 0.25 mm/px） |
| 跨屏落差 | 当前测得的错位量，拖动后才有读数，对齐后归零 |
| 已应用偏移 | 相对本次启动，已经写进系统的补偿量 |
| 撤销修改 | 一键回到启动前的排列（无可撤销内容时置灰） |
| 设置页（导航底部齿轮） | 主题（跟随系统/浅色/深色循环）、开机自动启动、关于（by UTwelve + 版本号） |

> 界面需要 Windows 11 的 Mica 材质与 Segoe Fluent Icons 字体。在 Windows 10 上仍可正常运行，
> 只是会退化为无材质的不透明背景、图标字体回落到 Segoe MDL2 Assets。

## 命令行参数

| 参数 | 作用 |
| ---- | ---- |
| `--demo` | 用内置的 **8 屏模拟布局**启动，不读写真实硬件，便于验证与演示 |
| `--arrange left\|right\|above\|below` | 走模拟布局，但把两台假显示器塞进真实桌面里**最大的一块屏**，好把「副屏在左/右/上/下」四种方位都在实机上截出来 |
| `--background` | 后台形态启动（开机自启用）：主窗口不出现，托盘常驻，泛光按存档恢复 |
| `--glow` | 启动即开启「边缘泛光」（演示模式下同样有效） |
| `--glowtest 0..1` | 强制所有接缝以固定强度常亮（截图验收用，不看鼠标位置） |
| `--page align\|glow\|dev\|settings` | 启动后落到指定导航页（截图验收用） |
| `--geomcheck` | 几何自检：对四个方位断言标尺摆位与补偿收敛，结果写入 `MonitorAlign-geomcheck.txt` 后退出（失败时退出码为 2） |
| `--navtest` | 导航栏自检：启动后每 0.9 秒自动换一页，把每次切换写进诊断日志（覆盖"从别的页切过来"这条用户真实路径） |
| `--overlaytest` | 只起标尺覆盖层、不起主窗口，并把窗口矩形与命中矩形写进探测文件，供验收脚本用 `WindowFromPoint` 验"按钮吃鼠标、空白处穿透" |
| `--info` | 自检模式：把探测结果与拓扑分析写入 `MonitorAlign-info.txt` 后退出 |
| `--lang en\|zh` | 强制界面语言，覆盖系统语言的自动判断 |
| `--diag` | 把启动过程写入 `%TEMP%\MonitorAlign-diag.txt`，排查问题时用 |

可组合使用：`MonitorAlign.exe --demo --lang en`

> `--arrange` 与 `--demo` 的区别：`--demo` 的 8 屏用绝对坐标，与真实桌面原点无关；
> 如果你的主屏不是坐标 (0,0) 那块（例如换成了靠右的竖屏），它的覆盖层会落到桌面之外。
> 想在实机上真看到标尺，用 `--arrange`。

### 覆盖层调试开关（一般用不到）

`--punch none`（负控：整窗吃鼠标）、`--fill 0..255`（给画布铺一层该 alpha 的纯黑底）、
`--glass off` / `--layered off` / `--act off`（DWM 玻璃、分层窗口、可激活性的 A/B 开关）。
这些是给命中测试做对照用的，正常使用不要加。

## 关于设置存档

程序会在 exe 同目录写一个小文件 **`MonitorAlign.settings.json`**，只记界面状态：
每条接缝的**标尺位置**（锚点）、**最后选中的接缝**、以及**边缘泛光的开关与全部参数**
（灵敏度/亮度/距离/接缝自定义颜色表）。下次打开时如果排列与存档一致就自动恢复。

对齐偏移量**不**在存档里 —— 补偿是通过系统的显示设置接口写进显示配置的（重启后依然生效），
系统本身就是持久层。程序只在内存里留一份启动时的排列快照，供「撤销修改」使用，退出即消失。

**排列与存档不符时（换过显示器、改过分辨率/缩放、在显示设置里挪过屏），存档会自动重置** —
锚点与接缝颜色表都只有在"当时那套排列"下才有意义，留着反而误导。

（更早的 `align.json` 记录的是偏移量，已移除：偏移是相对"当时"排列的增量，
一旦你在显示设置里改过排列，这份增量就是错的，套回去反而会把排列搞乱。）

## 已知限制（重要）

1. **两屏缩放比例不一致时无法全高度对齐。** 数学上跨屏落差会随高度线性变化，本工具在**接缝中点**精确对齐，两端仍可能有残余落差。建议把两屏缩放调成一致。
2. **倾斜（旋转）无法用软件补偿。** 只能物理调整。
3. **补偿后可能出现负坐标。** 个别老程序的窗口定位会异常，程序会在状态栏提示，可用「撤销修改」回退。
4. **系统可能重置排列。** 显卡驱动更新、插拔显示器、休眠唤醒、远程桌面都可能把排列打回默认——这种情况重跑一次本工具即可。
5. **全屏独占程序**（游戏、视频全屏）会遮挡标尺，需先退出全屏。
6. **只支持 64 位 Windows 10 1809 及以上。**

## 数据与隐私

只做一件事：改显示器的 `dmPosition`（逻辑位置）。不写驱动、不注入进程、不联网、不收集任何数据。
磁盘上只留 exe 同目录那个 `MonitorAlign.settings.json`（可随时删）。
